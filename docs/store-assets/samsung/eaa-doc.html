Annex: accessibility features

Summary of how Easy Xtream Football for Samsung Smart TV addresses the functional performance statements of EN 301 549 (clause 4) and the applicable requirements of Annex C. The application is a player: the audiovisual content, its subtitles and its audio tracks are supplied by the user's own provider.

Operation without vision or with limited vision

  • Dark, high-contrast theme throughout (light text on a dark background), with no information conveyed by colour alone: the focused element is also marked by a border and a size change.
  • Large user-interface text designed for a 1080p television: base size 24 px, titles 44 px, large cards and buttons.
  • Channel cards combine the logo with the channel name in text; logos are never the only identification.
  • Works with the television's own accessibility settings (such as high contrast, zoom and the Samsung voice guide for system controls).

Operation without hearing or with limited hearing

  • No function depends on sound: all feedback and all information are presented visually.
  • Subtitle tracks provided by the stream can be selected or switched off from the player menu; audio tracks (for example a described-video track, when the provider offers one) can be selected the same way.

Operation with limited manipulation or strength, and limited reach

  • The application is operated entirely with the television remote control: arrow keys, OK, Return, channel up/down and play/pause. No pointer, gesture, simultaneous key press or precise timing is required.
  • Text is entered only where unavoidable (provider credentials) using the television's on-screen keyboard, and only after the user presses OK on the field.
  • No action is time-limited: menus and dialogs stay open until the user closes them. Only the transient channel information overlay hides by itself, and it can be shown again at any time.

Operation with limited cognition

  • Simple, consistent structure: profiles, channel list, player. The same keys do the same thing on every screen, and a short key guide is shown on screen the first times the player is opened.
  • User interface available in 24 languages, following the television language.
  • Clear, plain-language error messages (for example when the provider cannot be reached), without technical codes as the only information.

Privacy and other requirements

  • The application does not collect personal data and does not use biometric features.
